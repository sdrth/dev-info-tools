# vite-react demo

Playground for `dev-info-overlay`.

![Demo with Dev Info Overlay open](../../media/demo-overlay.png)

## Run

From the repo root:

```bash
pnpm install
pnpm --filter vite-react-demo dev
# or: pnpm demo
```

Open http://localhost:5173 — use **Run fake agent turn**, then open the **DI** badge.

The overlay is forced `enabled` here so you can exercise the UI without setting env gates.
